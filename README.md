# Campus Card – React UI Project

A simple and visually appealing Campus Card interface built using React.js.

## About the Project

Campus Card is my first React UI project. It features a student card layout with a burgundy-inspired color theme and a clean design.

## Features

- Header component
- Student Card component
- Footer component
- Custom CSS styling
- Burgundy and red color palette

## Technologies Used

- React.js
- JavaScript
- CSS
- Vite
- Git & GitHub

## Project Structure

```text
src/
├── components/
│   ├── Header.jsx
│   ├── Card.jsx
│   └── Footer.jsx
├── App.jsx
└── index.css
```

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in your terminal.
